# 1. Objectif

`AuditActorMacros` fournit un macro Laravel permettant d'ajouter
les colonnes d'acteur responsables des opérations d'audit sur une table.

Le macro standardise les colonnes :

- `created_by`
- `updated_by`
- `deleted_by`

Ces colonnes permettent d'identifier l'utilisateur ayant effectué
l'opération correspondante.
