# MAHLINE — PASSWORD STANDARD

**Version:** 1.0
**Status:** GELÉ
**Domain:** Identity / Password

## 1. Purpose

This standard defines password creation, modification, validation and reset behavior.

## 2. Password policy

A valid password must:

* contain at least 12 characters;
* contain no more than 128 characters;
* contain at least one uppercase letter;
* contain at least one lowercase letter;
* contain at least one digit;
* contain no spaces.

Special characters are optional.

A new password must be different from the current password.

## 3. Password storage

Passwords must never be stored in plain text.

Only secure password hashes may be persisted.

## 4. Password change

A password change requires:

1. verification of the current password;
2. validation of the new password;
3. verification that the new password differs from the current password;
4. persistence of the new password hash;
5. security session handling.

After a successful password change, the affected active Web authentication session is revoked according to the authentication security workflow.

## 5. Password reset

Password reset uses a dedicated reset token.

Reset tokens:

* are generated cryptographically;
* are stored only as hashes;
* have an expiration time;
* can be used only once;
* are marked as used after successful reset.

A successful password reset revokes all active Web authentication sessions for the user.

## 6. Reset token security

The plain reset token must never be persisted.

The stored value is:

```text
SHA-256(token)
```

A token is rejected when:

* it does not exist;
* it has expired;
* it has already been used.

Invalid, expired and used tokens must not modify the user's password.

## 7. Forgot-password privacy

The forgot-password endpoint must not reveal whether an email address belongs to an existing user.

## 8. HTTP validation

Forgot-password requests validate:

* required email;
* valid email format;
* maximum email length.

Reset-password requests validate:

* required token;
* token type;
* required password;
* required password confirmation;
* matching confirmation.

## 9. Tests

Covered by:

* `PasswordPolicyTest`
* `PasswordServiceTest`
* `PasswordResetServiceTest`
* `ForgotPasswordRequestTest`
* `ResetPasswordRequestTest`
* `PasswordResetControllerTest`

## 10. Freeze rule

Any modification to password rules, hashing, reset tokens or session revocation must update the corresponding tests and this standard.
