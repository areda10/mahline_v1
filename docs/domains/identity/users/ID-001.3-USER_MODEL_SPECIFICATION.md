# Objectif

Ce document définit les spécifications techniques du modèle Eloquent `User`.

Le modèle User représente l'identité numérique d'un utilisateur du système MAHLINE.

Il constitue le point d'entrée principal de :

- l'authentification ;
- l'autorisation ;
- les sessions ;
- les API Tokens ;
- l'audit ;
- la sécurité.

---

# Emplacement

```text
app/Domains/Identity/Users/Models/User.php
```

```php

    'first_name',
```

# Hidden

Les attributs suivants doivent être cachés :

```php

    'password',
    'remember_token',
];
```

# Casts

```php
{
    return [
        'email_verified_at' => 'datetime',
        'password'          => 'hashed',
        'status'            => UserStatus::class,
    ];
}
```

# Authentification

Un utilisateur peut s'authentifier uniquement si :

```text
status = active
```

Les autres statuts sont refusés.

---

# Autorisation

Le modèle User ne doit contenir aucune logique métier complexe de permissions.

Les permissions sont gérées par :

```text
Role
Permission
RolePermission
UserRole
```

---

# Soft Delete

Le modèle utilise :

```php
SoftDeletes
```

Règle :

```text
ARCHIVED ≠ deleted_at
```

Ces deux mécanismes sont indépendants.

---

# Audit

Toutes les modifications du modèle doivent être auditables.

Colonnes obligatoires :

```text
created_by
updated_by
deleted_by
```

---

# Sécurité

Le modèle ne doit jamais :

- stocker un mot de passe en clair ;
- exposer le hash du mot de passe ;
- contourner les règles d'authentification.
