# 1. Objectif

Ce document définit les règles de création de données de test pour l'entité `User`.

Le `UserFactory` est exclusivement destiné à :

- l'environnement de développement ;
- les tests automatisés ;
- les tests fonctionnels ;
- les tests d'intégration ;
- le peuplement contrôlé des environnements de démonstration si explicitement autorisé.

Le Factory ne doit jamais être utilisé pour créer des comptes utilisateurs réels en production.

---
